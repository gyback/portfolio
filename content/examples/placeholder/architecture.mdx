# Architecture

## Content pipeline

Every page is an MDX file on disk. The build reads it, compiles it, extracts the
headings, and renders the result statically.

### Loading

A content module reads `meta.json`, validates it, and confirms each listed page
exists before the build continues.

### Compiling

MDX compilation runs through the standard remark and rehype toolchain. A small
remark plugin collects the h2 and h3 headings and exports them from the module.

## Layout

Three columns on wide screens. The centre column has a maximum reading width so
long paragraphs stay comfortable.

### Sticky columns

Both side columns are sticky and scroll independently of the content.

## Trade-offs

Compiling at build time means the site is fully static. The cost is that adding
a page requires a rebuild, which is the right trade for a portfolio.
